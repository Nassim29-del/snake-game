# 🐍 Snake Game

A classic Snake game built with Python. Guide the snake to eat food, grow longer,
and try to beat your high score without crashing into the walls or yourself!

## 🎮 Features

- Smooth snake movement with keyboard controls
- Snake grows each time it eats food
- Score tracking
- Game over when the snake hits a wall or its own tail

## 🛠️ Built With

- **Python 3**
- **Pygame** <!-- change to "Turtle (built into Python)" if you used turtle -->

## 🚀 How to Run

1. Make sure you have Python 3 installed:
   ```bash
   python3 --version
   ```

2. Install Pygame (skip this step if you used turtle):
   ```bash
   pip3 install pygame
   ```

3. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/snake-game.git
   cd snake-game
   ```

4. Run the game:
   ```bash
   python3 snake.py
   ```

## ⌨️ Controls

| Key | Action     |
|-----|------------|
| ↑   | Move up    |
| ↓   | Move down  |
| ←   | Move left  |
| →   | Move right |
